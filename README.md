# مسبحة (Tasbih) — تطبيق آيفون

تطبيق آيفون أصلي مبني بـ **SwiftUI** مع عدّاد لا نهائي، حفظ تلقائي للرقم، اهتزاز تفاعلي (Haptic Feedback)، وصوت نقرة خفيف مدمج مع إمكانية التوقيف والوضع الليلي والنهاري.

## المميزات
- **عدّاد لا نهائي (`BigCounter`)**: يحسب بدون حد أقصى (`Int64` أو غيره ما كيحبسوش)، ويحفظ الرقم تلقائياً على الآيفون.
- **حلقات 33 تسبيحة**: مؤشر دائري ناعم حول زر الضغط يكتمل كل 33 ضغطة مع استمرار العد الإجمالي إلى ما لا نهاية.
- **اهتزاز وصوت نقرة خفيف**: استجابة لمسية فورية (`UIImpactFeedbackGenerator`) وصوت نقرة مدمج لا يقطع الصوتيات الأخرى، مع أزرار تشغيل/إيقاف سريعة في الأعلى.
- **تراجع وتصفير آمن**: زر تراجع `-1` وزر تصفير مع نافذة تأكيد.

## كيفاش تخرج ملف `Tasbih.ipa` من Windows وتنستاليه على الآيفون

### 1. ارفع المشروع لـ GitHub
1. ادخل لـ GitHub وأنشئ مستودع (Repository) جديد (مثلاً باسم `tasbih-ios`).
2. من داخل مجلد المشروع على Windows شغّل:
   ```powershell
   git remote add origin https://github.com/<USERNAME>/tasbih-ios.git
   git push -u origin master
   ```
   *(أو `main` إذا كان الفرع الرئيسي عندك هو `main`)*

### 2. حمّل ملف `.ipa` الجاهز
1. افتح مستودعك في GitHub وادخل لتبويب **Actions**.
2. انتظر 2–3 دقائق حتى ينتهي مسار **Build Tasbih IPA** باللون الأخضر.
3. انزل لأسفل الصفحة لقسم **Artifacts** وحمّل **Tasbih-IPA** (ستجد بداخله `Tasbih.ipa`).

### 3. ثبّت `Tasbih.ipa` على الآيفون من Windows
1. حمّل أداة **Sideloadly** (أو **AltStore**) على Windows ووصّل الآيفون بالـ USB.
2. فعّل في الآيفون: **الإعدادات ← الخصوصية والأمان ← نمط المطور (Developer Mode)** إذا طُلب منك.
3. اسحب ملف `Tasbih.ipa` داخل **Sideloadly**، أدخل حساب Apple ID الخاص بك واضغط **Start**.
4. على الآيفون: **الإعدادات ← عام ← إدارة الأجهزة والملفات (VPN & Device Management)** ثم اختر حسابك واضغط **الوثوق (Trust)**.

> **ملاحظة Apple:** الحساب المجاني لـ Apple ID يوقّع التطبيق لمدة 7 أيام، وبعدها تعيد التوقيع بنفس الأداة (مع بقاء الرقم المحفوظ داخل التطبيق إذا لم تحذفه).
